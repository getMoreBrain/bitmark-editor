bitmark editor

bitmark and JSON editors on Monaco, with optional HTML, XML, Text, Info and Mappings panes, for any framework. Version __VERSION__.

Demos

  • Try it A static site with no bundler: the CDN build, the parser at its pinned version, light and dark themes.
  • Injected parser The page loads and initialises the parser itself; the editor never re-initialises it.

Documentation

  • API reference The core, the custom elements, the React adapter and the bundled build.
  • @gmb/bitmark-editor The package README: which build to use, quick starts, theming, sizes.
  • @gmb/bitmark-editor-angular Angular components: bm-session, bm-pane, bm-tabs, bm-split, with forms support.

Quick start: a static site

<bitmark-session lazy="idle" narrow="static" theme="auto" value="[.article]&#10;Hello">
  <pre data-bitmark-static>[.article]&#10;Hello</pre>
  <bitmark-pane type="bitmark" style="height: 300px"></bitmark-pane>
  <bitmark-pane type="json" style="height: 300px"></bitmark-pane>
</bitmark-session>
<script type="module" src="https://cdn.jsdelivr.net/npm/@gmb/bitmark-editor@__VERSION__/dist/bundled/bundled.js"></script>
