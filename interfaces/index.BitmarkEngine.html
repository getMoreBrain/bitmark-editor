    Interface BitmarkEngine

    The parser, as the editor uses it (PLAN-022 D2, D7, D14).

    Every call returns a promise, so a worker engine and a main-thread engine share one interface. A call the parser cannot answer resolves undefined (an older parser without that export); a parser error rejects with BitmarkEngineError.

    OptionalopenDocument

    • openDocument?(
          text: string,
          version: number,
          options?: { inputFormat?: string; views?: boolean },
      ): Promise<EngineDocument | undefined>

      Open text (at the editor's version) as a document (PLAN-035 D1). Resolves undefined when the parser, or the variant loaded, has no documents (a parser before 7.21; bitmark-json): the caller then uses the whole-text calls. Optional, so an engine written before it still fits. inputFormat: what the text is (default bitmark; PLAN-035 D7). views: the document is opened for its views, the output panes' conversions; a worker engine then keeps it beside its conversions, and an editor's own document on the lane that serves typing (PLAN-045 D2).
