    Interface BitmarkEngine

    The parser, as the editor uses it (PLAN-022 D2, D7, D14).

    Every call returns a promise, so a worker engine and a main-thread engine share one interface. A call the parser cannot answer resolves undefined (an older parser without that export); a parser error rejects with BitmarkEngineError.
